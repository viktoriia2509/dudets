# JOYSTICK site

Это разложенная по папкам версия сайта JOYSTICK. Исходный вариант был одним большим `index.html`, где одновременно лежали HTML, CSS и JavaScript. Сейчас структура ближе к обычному статическому сайту для GitHub Pages.

## Структура

```text
joystick-site/
├── index.html                 # HTML-разметка страницы
├── assets/
│   ├── css/
│   │   └── styles.css         # Все стили сайта
│   ├── js/
│   │   ├── config.js          # Настройки Firebase / Firestore
│   │   └── app.js             # Логика сайта и админки
│   ├── images/                # Папка под картинки, если будете хранить их файлами
│   └── docs/                  # Папка под PDF, если будете хранить их файлами
└── database/
    ├── firestore-rules.example
    └── README.md
```

## Как загрузить на GitHub

1. Создай новый репозиторий на GitHub.
2. Загрузи в репозиторий **содержимое папки `joystick-site`**, а не саму папку целиком. То есть `index.html` должен лежать в корне репозитория.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Сохрани. После публикации GitHub Pages выдаст ссылку на сайт.

## Что такое база данных в этом проекте

Сайт статический: GitHub хранит только файлы сайта. Заказы, товары, остатки, контакты и настройки хранятся отдельно — в Firebase Firestore.

В коде сейчас используется проект Firebase:

```js
firebaseProjectId: 'dedets-9cc2b'
```

Это находится в `assets/js/config.js`. Если создашь новый Firebase-проект, поменяй только это значение.

## Что важно по безопасности

Текущая админка сделана на фронтенде. Это значит: логин и пароль проверяются в браузере, а не на сервере. Для теста и простой демонстрации это работает, но это **не полноценная защита**. Любой технически грамотный человек может посмотреть код сайта.

Для нормальной коммерческой версии нужна авторизация через Firebase Authentication и закрытые Firestore Rules. Без этого Firestore обычно приходится оставлять публичным для записи, иначе GitHub Pages не сможет сохранять заказы напрямую из браузера.

## Как проверить локально

Можно просто открыть `index.html` двойным кликом. Но лучше открыть через локальный сервер:

```bash
python -m http.server 8000
```

Потом перейти в браузере на:

```text
http://localhost:8000
```

## Где редактировать

- Тексты, товары, остатки, документы — через админку сайта.
- Цвета и внешний вид — через админку или `assets/css/styles.css`.
- Firebase-проект — `assets/js/config.js`.
- Логика заказов, склада, модалок — `assets/js/app.js`.
