# JOYSTICK / dudets — версия 2

Это новая многостраничная версия сайта. Старый вариант был одним `index.html`, где товары, документы, контакты и калькулятор находились на одной странице. В этой версии структура разделена на отдельные страницы и файлы.

## Структура

```text
index.html              — главная страница
collection.html         — отдельная страница коллекции товаров
documents.html          — отдельная страница документов
contacts.html           — отдельная страница контактов
assets/css/styles.css   — весь дизайн сайта
assets/js/config.js     — настройки Firestore и проекта
assets/js/app.js        — логика сайта, корзины, регистрации и админки
assets/docs/            — сюда можно класть PDF-документы
assets/images/          — сюда можно класть изображения
```

## Что изменено

1. Сайт больше не одностраничный.
2. Товары вынесены на страницу `collection.html`.
3. Документы вынесены на страницу `documents.html`.
4. Кнопка «Контакт» заменена на «Контакты».
5. Калькулятор убран.
6. Добавлена корзина: товар → вкус → количество → итоговая сумма → оформление заказа.
7. Добавлены кнопки «Вход» и «Регистрация» для покупателей.
8. Регистрация требует согласия с документами по персональным данным.
9. В админке добавлены пользователи: можно смотреть, редактировать и видеть их заказы.
10. В админке расширены настройки шрифтов и размеров текста.
11. Настройки дизайна сохраняются только после нажатия «Сохранить дизайн».

## Как заменить файлы на GitHub

В репозитории нужно заменить старые файлы и папки на содержимое этой папки.

В корне репозитория должно быть так:

```text
index.html
collection.html
documents.html
contacts.html
README.md
SECURITY.md
assets/
database/
```

Не загружайте ZIP-файл как сайт. ZIP нужно распаковать, а на GitHub загрузить его содержимое.

## База данных

Сайт использует текущий Firebase Firestore-проект из файла:

```text
assets/js/config.js
```

Данные сохраняются в Firestore, если база доступна. Если Firestore недоступен, сайт работает через `localStorage` текущего браузера.

Ключи данных:

```text
products     — товары
texts        — тексты сайта
contacts     — контакты
site_docs    — документы
users        — зарегистрированные пользователи
orders       — заказы из корзины
design       — шрифты и размеры текста
admin_login  — логин админки
admin_pwd    — пароль админки
```

## Важно

Регистрация и вход покупателей реализованы на фронтенде. Это удобно для проверки логики, но не является полноценной защищённой авторизацией. Для реального магазина с персональными данными и заказами нужно подключать Firebase Auth или серверную авторизацию и закрывать правила Firestore.
