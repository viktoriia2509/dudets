# SECURITY NOTICE

В исходном сайте админ-логин и пароль находятся в клиентском JavaScript-коде. Это не является настоящей защитой.

Риски:

1. Любой посетитель может открыть исходный код сайта.
2. Если Firestore Rules разрешают публичную запись, данные можно изменить не только через админку.
3. Заказы содержат персональные данные: ФИО, телефон, email, комментарий. Их нельзя оставлять в публично доступной базе без контроля доступа.

Минимальный следующий этап для безопасной версии:

1. Подключить Firebase Authentication.
2. Перенести админку на авторизацию Firebase.
3. Разделить публичные данные и заказы по разным коллекциям.
4. Настроить Firestore Rules так, чтобы админские операции были доступны только авторизованному администратору.
5. Для уведомлений Telegram/WhatsApp использовать backend-функцию, а не открывать всё из браузера.
