# База данных Firestore

Сайт хранит данные в Firebase Firestore в коллекции `settings`. Каждый документ коллекции — отдельный ключ сайта.

## Документы коллекции `settings`

```text
products
texts
contacts
design
site_docs
users
orders
admin_login
admin_pwd
```

Внутри каждого документа используется поле `v`, где лежит значение ключа.

## Восстановление

Возможны три сценария.

1. Firestore пустой, но старые данные остались в браузере. Тогда открой сайт в этом браузере, зайди в админку и нажми **Настройки → Восстановить Firestore из этого браузера**.

2. Firestore пустой и в браузере старых данных нет. Тогда можно восстановить только базовые товары/документы через **Сбросить Firestore к базовым данным**. Старые заказы и пользователи не восстановятся.

3. Есть официальный Firestore export/backup. Тогда восстановление делается через Google Cloud / Firebase import-restore.

## Реальное время

В этой версии сайт автоматически опрашивает Firestore примерно каждые 8 секунд и обновляет публичные страницы, заказы и пользователей. Это практичная синхронизация для GitHub Pages без собственного сервера.

Для настоящих realtime listeners нужно подключать Firebase SDK и `onSnapshot`, а для защищённой работы пользователей — Firebase Auth и Firestore Security Rules.
