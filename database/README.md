# База данных Firebase Firestore

Сайт использует Firebase Firestore как облачную базу данных. GitHub Pages — это только хостинг файлов, он не хранит заказы и не является базой данных.

## Что хранится в Firestore

Используется коллекция `settings`. В ней сайт хранит документы-ключи:

- `products` — товары, линейки, вкусы, цены;
- `images` — ссылки или base64-фото;
- `texts` — тексты сайта;
- `contacts` — Telegram, WhatsApp, телефон, email;
- `colors` — цвета сайта;
- `font` — выбранный шрифт;
- `pd_config` — настройки чекбоксов и ссылок на документы по персональным данным;
- `orders` — заказы и предзаказы;
- `stock` — остатки товаров;
- `site_docs` — документы и сертификаты.

## Как создать новую базу

1. Зайди в Firebase Console.
2. Создай новый project.
3. Открой `Build` → `Firestore Database`.
4. Нажми `Create database`.
5. Выбери регион.
6. Для быстрого теста можно использовать тестовые правила, но это небезопасно.
7. Скопируй Project ID и вставь его в `assets/js/config.js`.

## Важное ограничение

Сайт работает без сервера. Все запросы в Firestore идут прямо из браузера. Поэтому безопасная схема должна быть такой:

- публичная часть сайта может читать только разрешённые публичные данные;
- запись заказов должна быть ограничена правилами;
- админка должна работать через Firebase Authentication;
- логин и пароль нельзя хранить в JavaScript-коде.

В текущей версии это пока не реализовано, потому что задача была сохранить работоспособность исходного сайта и разложить его по файлам.
