# База данных

В этой версии база данных — это Firebase Firestore. GitHub хранит только файлы сайта, а данные сайта хранятся отдельно.

Файл с настройкой проекта:

```text
assets/js/config.js
```

Текущая коллекция Firestore:

```text
settings
```

Каждый раздел сайта сохраняется отдельным документом в коллекции `settings`.

Пример:

```text
settings/products
settings/orders
settings/users
settings/design
settings/site_docs
```

Если Firestore недоступен, сайт сохраняет данные в `localStorage` браузера. Такие данные видны только на том устройстве и в том браузере, где они были созданы.

Для проверки интерфейса этого достаточно. Для реального использования с заказами и персональными данными нужна нормальная авторизация и закрытые правила доступа.
